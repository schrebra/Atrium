Atrium: screenshot gallery

Every screen of the Atrium client and admin console, captured from build 261120_1140. Atrium is a self-hosted team chat for internal networks that runs fully offline. Click any screenshot to view it full size. Repository: github.com/schrebra/Atrium

Not pictured: the desktop shell window (the WPF/WebView2 host). It renders this same client; a capture of the shell chrome itself requires a Windows machine.
