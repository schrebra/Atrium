# Contributing

Atrium is a solo project in early alpha, built under a strict doctrine (see [doctrine.md](doctrine.md)) and delivered as a single self-contained PowerShell installer.

**Issues and discussion are welcome.** The most useful bug reports name the build (the CalVer stamp), what was expected, what happened, and how to reproduce it.

**Pull requests are not accepted at this time.** The whole system — application, schema, installer — is generated from one script under one set of working principles; outside code cannot be merged without breaking that model. This may change after the alpha phase.

The code is published for inspection and evaluation. See the repository's license file for the terms of use.
